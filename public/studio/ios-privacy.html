iPhone 앱 도움말

시니어그램 · iPhone 앱 1.0

사진과 문구는
이 기기에서 처리해요.

적용 범위: 로그인·서버 업로드·결제·광고·분석 SDK가 없는 iPhone 카드 제작 앱 1.0. 웹 서비스에는 별도의 웹 개인정보 안내가 적용됩니다. 앱은 애플 등록 준비 중입니다.

앱에서 처리하는 내용

사용자가 직접 적은 받는 이름, 보내는 분, 제목과 문구, 사용자가 사진 선택창에서 고른 사진을 카드 제작에 사용합니다. 카드 편집과 이미지 출력은 iPhone 안에서 이루어지며, 이 앱이 해당 내용을 운영 서버나 AI 서비스로 전송하지 않습니다.

앱에는 회원 계정, 광고 식별자 수집, 분석·추적 SDK가 없으며, 카드 내용이나 사용 기록을 운영자에게 자동으로 보내지 않습니다.

음성과 마이크

‘말로 하기’를 누를 때만 음성 인식과 마이크 권한을 요청합니다. 한국어 기기 내 음성 인식을 지원하는 경우에만 기기 내 인식을 요구하여 녹음을 시작합니다. 인식 결과는 사용자가 확인한 뒤 카드 종류와 받는 이름에 적용됩니다. 앱은 녹음 파일을 보관하지 않으며 운영 서버로 음성을 전송하지 않습니다.

기기 내 인식이 지원되지 않거나 권한을 거절해도 글로 요청하거나 카드 종류를 골라 사용할 수 있습니다. 화면을 닫거나 앱이 비활성화되면 듣기를 멈추며, 한 번에 최대 45초 동안 입력합니다.

사진 선택과 사진 앱 저장

사진 선택에는 iOS 사진 선택창을 사용합니다. 사용자가 선택한 사진만 앱으로 전달되며, 사진 전체 목록에 대한 읽기 권한을 요청하지 않습니다. 선택 사진은 편집에 필요한 크기로 줄여 처리하며, 임시로 복사한 가져오기 파일은 처리 후 제거합니다.

완성 카드를 사진 앱에 저장할 때는 ‘사진 추가’ 권한만 요청합니다. 사용자가 저장한 이미지는 사진 앱과 해당 기기의 iCloud 설정에 따라 보관됩니다.

기기 보관함과 삭제

사용자가 ‘내 작품에 보관’을 선택하면 완성 카드 이미지와 제목·보관 시각·파일 크기를 앱 전용 공간에 저장합니다. 저장 한도는 50개·100MB입니다. 큰 글씨 선택은 앱 설정에 보관합니다. 이 보관함은 다른 기기와 자동 동기화하지 않으며, 운영자가 읽을 수 없습니다. iOS 기기 백업에 포함되는지는 사용자의 백업 설정을 따릅니다.

내 작품에서 개별 작품을 삭제할 수 있고, 앱을 삭제하면 앱의 로컬 데이터가 제거될 수 있습니다. 사진 앱에 저장한 이미지, 기기 백업과 외부 공유본은 각각 해당 저장소에서 직접 삭제해야 합니다. 계정을 만들지 않으므로 회원 탈퇴 절차는 없습니다.

외부 공유와 문의

공유 버튼은 iOS 공유창을 열며 사용자가 보낼 앱과 받는 사람을 선택합니다. 선택한 서비스로 전달된 뒤의 처리는 해당 서비스의 정책을 따릅니다. 앱에서 자동 발송하거나 운영자에게 사본을 보내지 않습니다. 도움말의 외부 링크를 열면 브라우저와 방문 사이트에서 접속 정보를 처리할 수 있습니다.

이메일·전화 문의는 사용자가 직접 외부 이메일 또는 전화 앱을 열어 시작합니다. 문의를 보내면 운영자는 회신을 위해 사용자가 보낸 연락처와 문의 내용을 받을 수 있습니다. 민감한 개인정보나 개인 사진은 보내지 마세요.
