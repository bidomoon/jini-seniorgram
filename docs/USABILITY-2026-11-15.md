# 시니어 실사용 가정 정밀 검사

검사일: 2026-11-15 한국 시간. 대상: https://jini-seniorgram.netlify.app/ . 사용자가 요청한 **동일한 연결 Chrome 브라우저**에서 검사했습니다. 실제 65세 이상 참여자의 사용성 조사와 발화 인식률 측정을 완료했다는 뜻은 아닙니다.

## 실제로 재현하고 고친 오류

| 문제 | 수정 전 실제 화면 | 수정과 재검증 |
| --- | --- | --- |
| 무응답 후 듣기 안내가 남음 | 마이크 버튼은 대기 상태로 돌아왔는데 ‘듣고 있어요’ 안내가 남았습니다. | 종료·오류·시작 실패·시간 초과에 상태를 정리합니다. 실제 마이크 시작 후 무응답 종료와 직접 중지에서 재시도 안내를 확인했습니다. |
| 일상적인 인사가 비활성 AI로 연결됨 | ‘아침 인사 만들어줘’를 요청 확인란에 넣고 계속을 누르자 사용 불가인 AI 그림 화면으로 이동했습니다. | 무료 인사 카드로 분류합니다. 동일 문장으로 실제 카드 편집 화면 진입, 이름·보내는 분 변경, PNG 완성까지 확인했습니다. **문장 전달은 글 입력 경로였고 실제 발화 인식 성공 사례로 계산하지 않습니다.** |
| 모바일 카드 완성 버튼이 하단 메뉴에 가림 | 큰 글씨에서 만들기 버튼 y=766.8–832, 하단 메뉴 y=768–844. 버튼 중앙의 실제 터치 대상이 ‘내 작품’이었고 누르면 보관함으로 이동했습니다. | 고정 메뉴·마이크 위에 공간을 확보했습니다. 버튼 하단 y=684, 마이크 상단 y=697.2, 메뉴 상단 y=768로 분리됐습니다. 동일 위치에서 실제 클릭 후 카드 완성 화면과 영상 제작 화면에 진입했습니다. |

음성 확인 화면에 다시 말하기와 단계 안내를 추가했습니다. 이름·문구 변경, 카드 완성, 기기 보관, 처음 화면 이동 명령을 지원합니다. AI가 비활성인 경우 ‘접수했다’고 알리지 않고 무료 카드로 돌아가는 버튼을 제공합니다. 화면을 이동하면 남은 음성 확인 요청을 지우며, 편집 화면에서도 접근할 수 있는 마이크 버튼을 추가했습니다.

## 자동 검사와 배포

- 전체 13개 회귀 테스트, TypeScript, 프레임워크 빌드, Netlify 빌드를 통과했습니다. 서버·구매·음성 서비스 응답은 가상 처리합니다. 실제 PostgreSQL 엔진 검사도 실제 운영 DB 연결의 증거는 아닙니다.
- `tests/voice-states.cjs`: 무응답 종료, 권한/서비스/장치/네트워크 오류, 시작 실패, 응답 없는 시작의 시간 제한, 중간 인식의 확인 요구, 늦게 도착한 콜백 차단, 화면 숨김, 800자 제한, 페이지 이동, 준비 전 유료 요청 차단, 중복 실행 방지.
- `tests/studio-local-flow.cjs`: 실제 음성 컨트롤러와 카드 코드의 연결을 검사합니다. 여기서는 Canvas와 인식 입력이 가상입니다.
