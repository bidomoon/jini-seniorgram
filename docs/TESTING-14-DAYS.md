# 시니어그램 비공개 테스트 운영

목표: 2026-10-08 18:00 KST부터 2026-10-22 18:00 KST 이후까지 연속 14일. 실제 시작이 늦으면 종료·신청일도 늦어진다. Play Console의 참여 상태와 기간을 기준으로 판단한다. 실제 참여자를 꾸미거나 참여 기록을 생성하지 않는다.

15–20명 모집, 최소 12명 연속 옵트인 유지 목표. Android 8 이상 중 저사양/오래된 갤럭시와 최신 갤럭시, 작은/큰 화면, 큰 글씨, Wi-Fi/모바일 데이터 이용자를 섞는다. 앱은 특정 모임 전용이 아니며 테스트 그룹은 검증에만 사용한다.

AI·영상·스토어 결제는 운영자가 승인한 테스트 예산과 라이선스 테스트 계정으로만 실시한다. 실제 API 호출을 했는지, mock인지, 어떤 기기인지 구분하여 기록한다. 기능이 준비되지 않아 실행하지 못한 항목은 통과로 표시하지 않는다.

## 결함 분류와 출시 중단 기준

- P0: 다른 사람의 비공개 작품 노출, 중복 과금, 미동의 공개, 계정 탈취. 즉시 관련 기능 중단·수정·재검증.
- P1: 설치/로그인/제작/저장/핵심 공유 불가, 구매 권한 미지급, 해지 후 잘못된 갱신, 탈퇴 불가. 오픈 전 0건.
- P2: 비핵심 문구/레이아웃/편의 문제. 영향과 우회 방법, 수정 계획을 기록하고 출시 판단.
- 서버 오류율/생성 시간/완성률/저장 실패/중복 방지/문의 미처리 건수를 실제 기록으로 평가. 아직 수치가 없으므로 성능을 달성했다고 주장하지 않는다.

## 테스트 기록 양식

실명·연락처 대신 T01~T20 식별자를 사용한다. 참여자 이메일은 Play 테스트 그룹의 비공개 관리 화면에서만 관리한다. 실제 화면에 개인정보가 보이면 가린 뒤 공유한다.

`테스터ID | 기기/OS | 앱버전 | 시작시각KST | 시나리오 | 성공/실패/미실행 | 도움 필요 | 재현 단계 | 심각도 | 수정 버전 | 재검증 결과`

프로덕션 접근 신청 시 모집 방법, 실제 테스트 사용 내용, 받은 피드백, 고친 문제, 대상 사용자와 앱의 가치, 출시 준비 판단을 실제 기록으로 작성한다. 최소 인원·기간만으로 승인이 보장되지 않는다.
