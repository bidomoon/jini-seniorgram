## 실제 연결 순서

1. 시니어그램 전용 PostgreSQL을 정하고 `DATABASE_URL`을 서버 환경변수에 보관한다. 다른 서비스 DB를 임의 재사용하지 않는다. 외부 DB는 인증서를 검증하는 TLS 연결을 사용한다.
2. 운영자가 승인한 전용 DB에서 `MIGRATION_CONFIRM=seniorgram-dedicated-database node scripts/migrate-postgres.mjs` 실행. 비밀은 쉘 이력이나 소스가 아닌 보안 환경변수로 전달. 적용 후 `PRODUCT_SCHEMA_VERSION=3` 설정.
3. Netlify `jini-seniorgram` > Project configuration > Environment variables > Functions에 카카오 키 등록. `APP_ORIGIN=https://jini-seniorgram.netlify.app`, `KAKAO_REST_API_KEY`, `KAKAO_CLIENT_SECRET`. 카카오 Redirect URI는 `https://jini-seniorgram.netlify.app/api/auth/kakao/callback`.
4. 개인정보처리방침·이용 안내·사업자/연락처·해외 처리 고지를 확정하고 실제 두 계정 로그인 검증 후 `KAKAO_LOGIN_ENABLED=true`.
5. AI·저장 기능은 별도 통제: `OPENAI_API_KEY`, `GEMINI_API_KEY`, `MEDIA_STORAGE_ENABLED=true`, `GENERATION_ENABLED=true`, `GENERATION_DAILY_LIMIT`, `VIDEO_GENERATION_ENABLED=true`, `VIDEO_DAILY_LIMIT`, `TRIAL_ENABLED=true`, `JOB_SWEEPER_ENABLED=true`. 비용/안전 테스트 전에는 enabled 값을 켜지 않는다. 환경변수 이름과 기능 준비는 과금 테스트 승인과 다르다.
6. `COMMUNITY_ENABLED=true`, `ADMIN_ACCOUNT_IDS=<운영자 계정 UUID>`를 실제 운영 인력과 검사 확인 후 설정. `/manage.html`은 서버가 지정 운영자만 허용한다.
7. 실 결제는 코드상 차단 유지. 웹 KakaoPay 가맹점 계약과 Android Play Billing 상품/검증을 각각 완성·검증한 뒤에만 판매 활성화한다.
8. Netlify는 현재 팀 로그인 제한이 있어 일반 테스터와 스토어 심사자가 접근할 수 없다. 공개 범위 변경은 승인 후 적용한다. 정책/삭제 URL도 외부에서 열려야 한다.

## Google Play 등록 자료

- 계정 소유자: 개인/조직 유형, 본인/사업자 인증, 개발자 연락처, 기기 인증 해당 여부 확인.
- Android application ID 후보 `app.jininova.seniorgram` (첫 업로드 전 확정; 업로드 후 변경 불가).
- 제출: 실제 업로드 키로 서명한 `.aab`. CI의 unsigned AAB는 바로 제출할 수 없다. 서명키는 소스에 넣지 않는다.
- Play App Signing 인증서 SHA-256을 `ANDROID_APP_SIGNING_SHA256`에 넣고 `node scripts/assetlinks.mjs` 실행 후 웹에 배포. 업로드 키와 앱 서명 인증서는 다를 수 있다.
- 앱 이름 시니어그램 / 짧은 설명안: “말로 쉽게 그림과 영상 카드를 만들고 가족·친구와 나누세요.”
- 실제 작동 화면의 휴대폰 스크린샷 2장 이상, 512×512 아이콘, 1024×500 그래픽. 아직 촬영하지 않은 화면을 실사용 화면으로 제출하지 않는다.
- 개인정보처리방침, 앱 밖 계정 삭제 URL, Data safety의 회원번호/닉네임/요청/생성 결과/공개 콘텐츠/문의/음성 처리와 실제 공급자 전송을 일치시킨다.
- 콘텐츠 등급, 광고 여부(현재 광고 없음), 대상 연령, AI 생성 콘텐츠 신고, UGC 신고·차단·운영 연락처.
- 심사 접근 안내: Netlify 팀 로그인 제거 승인, 카카오 심사 접근 방법과 실제 체험 제공. 기능 제한/접속 실패를 숨기지 않는다.
- 결제: Play 상품 설정과 서버 구매 검증·승인·갱신·복원·취소/환불 반영. 웹 카카오페이를 앱 디지털 구독의 유일 결제로 가정하지 않는다.

## 즉시 필요한 소유자 정보

Google Play Console 계정(개인/조직)과 접근, 카카오 개발자 앱 설정, 전용 DB 선택/비용, Google 영상 API 키, 가맹점 사업자 정보, 운영 문의 연락처, 서명키 관리 담당자, 비공개 테스트 참여자 그룹. 키를 채팅에 붙이지 않고 지정 환경변수나 서비스의 보안 설정으로 등록한다.
