# 시니어그램 앱 개발 현황 · 2026-11-07

시니어그램은 독립된 스마트폰 앱으로 출시하는 제품입니다. Android를 먼저 준비하며 iPhone 앱은 후속 단계입니다. 현재 Android는 Google의 Android Browser Helper를 사용하는 TWA 구조로 운영 웹앱을 엽니다. 앱과 웹 도메인의 실제 서명 인증이 완료돼야 브라우저 도구막대 없이 표시됩니다.

## 이번 변경

- Android 테스트 버전 기본값을 `0.2.0-debug`로 올리고 설치 이름을 `시니어그램 테스트`로 구분했습니다. 기존 출시 패키지 ID는 유지합니다.
- 카드 완성 → 편집 → 디자인 선택을 휴대폰 뒤로가기·앞으로가기로 이동할 수 있습니다. 현재 페이지 기록에는 화면 이름과 위치만 저장하며 사진·음성·입력 문구는 넣지 않습니다.
- 녹음·파일 생성 중에는 화면 이동과 앱 업데이트가 작업을 끊지 않도록 막습니다.
- 새 버전이 준비되면 파일 저장을 안내한 뒤 사용자가 업데이트 버튼으로 적용합니다. 자동 새로고침으로 편집 파일을 잃지 않게 합니다.
- 오프라인 안내 화면과 캐시의 CSS 버전을 맞췄습니다. 공개 안내·CSS·아이콘만 캐시하며 계정 API·작품 파일·로그인 응답은 캐시하지 않습니다.
- 큰 글씨에서 앱 로고와 하단 메뉴가 글자 중간에서 줄바꿈되는 문제를 보완했습니다.
- Android 빌드 검사를 웹 화면 변경에도 실행하고, 화면 이동 회귀 검사를 CI에 추가했습니다.

## 확인한 범위

- Chromium에서 360·390·430·768·1280 너비의 큰 글씨, 학습 진도 유지, 예시 카드 생성·다운로드, 뒤로가기·앞으로가기, 파일 생성 중 이동 차단을 확인했습니다.
- 서비스워커의 새 버전 적용, 인터넷 단절 시 안내와 스타일 표시, 비공개 API 캐시 제외를 확인했습니다.
- 기존 음성·계정·결제·DB 접근·작품·API·생성 작업의 로컬 회귀 검사를 통과했습니다. 외부 AI·결제 API는 모의 응답으로 검증했으며 유료 요청은 보내지 않았습니다.

## 출시 전 남은 항목

- 실제 Android 기기에서 설치·마이크 권한·카카오톡 파일 공유·중단 후 복귀 시험.
- 실제 카카오 로그인, 전용 회원 DB, AI 이미지·영상과 회원 작품 보관의 운영 연결 검증.
- Play Console 업로드 키와 Play App Signing 인증서 확인, 도메인의 Digital Asset Links 연결, 서명 AAB 생성 및 비공개 테스트.
- Google Play 결제 검증·복원·갱신·환불 처리와 실제 결제 시험.
- iOS 앱 구현 및 Apple 배포 계정·심사 준비.

디버그 APK 생성, 운영 웹 배포, 실물 기기 시험, 스토어 제출·승인은 서로 다른 단계입니다. APK가 만들어졌다는 사실만으로 앱 출시나 회원·AI·결제 연결이 완료된 것으로 보지 않습니다.
