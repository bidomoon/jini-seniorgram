## 고객 흐름

접속/설치 → 카카오 로그인 → 무료 AI 체험 → 저장/공유 → 이용권 선택 → 명시적 정기결제 동의.
로그인 전에는 준비된 카드로 바로 체험할 수 있습니다. 체험 시작에 카드 등록을 요구하지 않고, 체험 종료로 자동 유료 전환하지 않습니다.
첫 체험은 아침 인사·손주 생일·감사 인사에서 선택합니다. 글/음성을 모두 유지합니다.

## 9월 26일 현재 구현 범위

- 큰 로그인/체험/이용 요금 버튼과 요금제 안내, 세 가지 첫 카드 체험 시작점.
- Netlify Functions용 카카오 OAuth: state 일회성 검증, 서버 토큰 교환/회원조회, 해시 세션, HttpOnly/Secure 쿠키, 로그아웃 시 세션 폐기.
- PostgreSQL 계정/세션/체험/테스트 주문 스키마. **운영 DB 연결·마이그레이션은 아직 미실행.**
- 카카오페이 **테스트 가맹점 TCSUBSCRIP만** 사용하는 결제 준비/승인 코드. 서버가 가격 결정, 주문 중복 방지, 사용자·금액·주문 검증.
- **실제 구독 판매/자동 갱신/해지/환불은 아직 미구현이며 실결제 엔드포인트는 항상 차단.** 테스트 승인도 유료 권한을 주지 않음.
- 실제 카카오 키·DB·카카오페이 개발 키가 없으므로 공급자 실연동은 아직 미검증.
- AI 체험권 DB 구조만 준비되어 있음. Netlify AI 작업 이식 전에는 체험권 발급·사용 버튼을 열지 않음.
- 모의 통합 테스트: state 재사용·CSRF·세션폐기·가격변조·중복요청·금액불일치·실결제 차단.

## 연결 설정

Netlify 프로젝트: `jini-seniorgram`, 팀: `jini-nova`.
서버 환경변수에는 아래 값을 넣습니다. 키는 채팅이나 GitHub에 올리지 않습니다.

| 이름 | 값/준비처 |
| --- | --- |
| `APP_ORIGIN` | `https://jini-seniorgram.netlify.app` |
| `KAKAO_REST_API_KEY` | 카카오디벨로퍼스의 시니어그램 앱 REST API 키 |
| `KAKAO_CLIENT_SECRET` | 같은 앱 REST API 키의 클라이언트 시크릿 |
| `KAKAO_LOGIN_ENABLED` | 실제 앱 설정·DB·개인정보 고지 완료 후 `true` |
| `DATABASE_URL` | 시니어그램 전용 PostgreSQL TLS 연결 주소. 공유 사업 데이터 DB에 임의 설치하지 않음 |
| `KAKAOPAY_TEST_SECRET_KEY` | 카카오페이 개발자센터의 개발용 Secret key |
| `KAKAOPAY_TEST_ENABLED` | 테스트 실행 준비 완료 후 `true` |

카카오 Redirect URI: `https://jini-seniorgram.netlify.app/api/auth/kakao/callback`
카카오페이 웹 도메인: `https://jini-seniorgram.netlify.app`
개발 단계에서는 실제 가맹점 키를 입력해도 실결제를 허용하지 않습니다.
DB SQL: `migrations/postgres/001-accounts.sql`. 마이그레이션은 배포 요청 중 자동 수행하지 않으며, 승인된 DB에 운영자가 별도로 적용합니다.
