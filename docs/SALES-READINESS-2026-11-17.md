# 시니어그램 판매 준비 점검 — 2026-11-17 KST

## 판단

월 구독 판매는 아직 시작하지 않는다. 현재 작동하는 카드 만들기와 기기 보관 기능은 무료 체험·수업 실습에 사용할 수 있다. 유료 이용자가 기대하는 실제 AI 생성, 계정 보관, 구독 구매·갱신·해지 경로는 운영 연결과 실증이 남았다. 디자인 개선과 로컬 자동검사를 상용 서비스 완성으로 해석하지 않는다.

## 반영한 사용성 개선

- 첫 화면에서 안내와 사용 불가인 AI 기능보다 무료 카드 제작을 먼저 제시한다.
- 안부·생일·감사·응원은 편집 화면으로 바로 이어진다. 사진 꾸미기는 실제 사진 선택 항목을 펼친다.
- 말로 하기의 큰 패널은 요청할 때만 창으로 연다. 문장 확인 후에만 동작하며, 완료 안내는 창을 닫은 뒤에도 표시한다.
- 하단 메뉴는 만들기·내 작품·사용법으로 정리하고 현재 위치를 표시한다.
- AI 그림·AI 영상·작품 모임은 서버가 사용 가능 상태를 반환하기 전까지 비활성이다. 연결 조회 실패도 별도 표시한다.
- 로그인·무료 AI 체험과 요금을 사용할 수 있는 것처럼 첫 화면에서 홍보하지 않는다.
- 완성 화면의 앱별 상세 공유 방법을 접어두고 저장·공유를 우선한다. 게시되지 않은 작품 링크와 미연결 피드 게시 버튼을 노출하지 않는다.
- 첫 화면에서는 고정 마이크가 콘텐츠를 가리지 않도록 상단의 말로 만들기 버튼을 사용한다. 다른 화면의 마이크 접근은 유지한다.

## 확인한 사실

- 수정 초기 전체 자동검사 16종, TypeScript 검사, 프레임워크 빌드, Netlify 배포 빌드 통과.
- 추가 완성 화면 수정 후 카드·음성 통합 검사와 음성 상태 검사를 다시 통과. 외부 유료 API 호출 없음.
- 공개 사이트의 새 첫 화면, 실제 음성 안내 창, 요청 문장 입력·확인 → 손주 생일 카드 편집 → 이름 입력 → 실제 1080×1080 PNG 생성 → 기기 보관 → 보관함 재열기를 같은 Chrome에서 확인했다. 기존 보관 작품은 삭제하지 않았다.
- 390×844 뷰포트 시험에서 실제 콘텐츠 폭은 스크롤바 제외 375px였고 가로 넘침이 없었다. 첫 만들기 버튼은 하단 고정 메뉴 위에 표시됐다. 이는 Chrome의 화면 크기 시험이며 실제 iPhone/Android 시험은 아니다.
- 앱 콘솔 오류는 최초 확인 시 0건이었다. 후속 배포와 보정 화면은 추가 확인 후 아래 기록한다.
- 공개 서버 응답에서 database/storage/imageReady/videoReady/communityReady/trialAvailable/loginReady/checkoutReady는 false였다. 전용 DB와 카카오 키를 준비한 것만으로 앱 연결이 완료된 것은 아니다.

## 미확인·미완료

- 사람의 실제 발화를 통한 인식률, 소음 환경, 휴대폰 마이크 권한·키보드·세로 화면 동작.
- 실제 사진 선택, 휴대폰 사진 앱 저장, 카카오톡·SNS 수신자에게 최종 전송.
- 보관함의 파일 저장 링크를 눌렀으나 자동화 도구가 다운로드 이벤트를 12초 안에 포착하지 못했다. 파일 저장 성공 또는 앱 오류 어느 쪽으로도 단정하지 않는다.
- 전용 DB의 서버 연결 문자열·TLS 확인, 카카오 실계정 로그인, 별도 회원 간 작품 접근 차단 실증. Supabase 관리 화면은 사용자 로그인이 필요하다.
- 카카오 연결 해제 처리와 최종 개인정보 고지, 실제 AI 생성 비용·제공 횟수 확정.
- Google Play 실제 구독 구매·복원·갱신·만료·해지 실증, 스토어 제출·심사.

## 권장 판매 순서

무료 체험으로 시니어가 도움 없이 카드 한 장을 완성·보관·전송하는지 확인한다. 이후 로그인 → 실제 AI 생성 → 계정 보관 → 이용권 구매·해지까지 실증한 뒤 월 구독을 개방한다. 새로운 유료 API 시험이나 비용 추가는 승인받은 예산과 횟수 안에서만 수행한다.
